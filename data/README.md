# 数据和模板

请从题目发布方或你已获得授权的材料中取得 C 题附件；没有原始附件时，仍可
阅读源码、查看参考汇总并运行合成测试。仓库不包含第三方题目或附件。

默认布局：

```text
data/
  raw/
    附件1.xlsx
    附件2.xlsx
    附件3.xlsx
    附件4.xlsx
  templates/
    result1.xlsx
    result2.xlsx
    result3.xlsx
    result4-2.xlsx
    result4-3.xlsx
```

也支持 `--data-dir /path/to/附件`：四个数据文件位于该目录，模板位于其
`附件5/` 子目录。`data/templates/` 中存在同名文件时优先使用项目模板。

附件 1 提供固定分时电价与 Q1 数据；附件 2 包含“小区负载”和
“光伏发电实际功率”工作表；附件 3 提供 0/6/12/18 光伏预报；附件 4 提供
逐日电价。模板需保留原工作表名称、日期和时间列，程序根据题目格式填值。
`--check-inputs` 只检查所选问题需要的文件和模板是否存在，不验证全部单元格。

输入和模板目录均由 `.gitignore` 排除。不要为方便上传而移除这些规则；若以后
确认有再分发许可，应另行注明来源与适用许可。
